# Code of conduct

Be respectful, specific and constructive. Discuss technical claims with evidence.
Harassment, discriminatory language, threats, disclosure of private information,
and attempts to pressure contributors into unsafe production tests are not
acceptable.

Maintainer [Brahim Rizq](https://github.com/brahimrizq) may edit or remove abusive
content and restrict participation. Ordinary moderation requests can identify
the relevant public issue or pull request without repeating sensitive content.
For confidential platform-abuse reports, use GitHub's **Report abuse** control;
do not publish personal details in this repository. Security vulnerabilities use
the private route in SECURITY.md.

This policy applies to repository issues, pull requests and other project spaces.
It does not promise a response deadline or a separate private moderation inbox.
